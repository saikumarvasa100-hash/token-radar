A token launch radar that ranks 200 pre-token DeFi protocols by implied value using a transparent, snapshot-derived model with category benchmarks, chain premiums, growth and maturity factors, and TVL scale adjustments. Each protocol includes a concrete 6-step farm plan specific to its category and chain mix.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
